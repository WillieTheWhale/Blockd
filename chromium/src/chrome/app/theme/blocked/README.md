# Blocked Browser Branding

This directory contains branding resources for the Blocked Interview Browser.

## Files

- `BRANDING` - Product and company name definitions
- `product_logo_*.png` - Application icons (16x16, 32x32, 48x48, 64x64, 128x128, 256x256)
- `installer_logo.bmp` - Windows installer logo
- `background.png` - macOS DMG background image

## Icon Requirements

### Windows
- 16x16, 32x32, 48x48, 256x256 PNG icons
- Combined into .ico file by build system

### macOS
- 16x16, 32x32, 128x128, 256x256, 512x512, 1024x1024 PNG icons
- Combined into .icns file by build system

### Linux
- 16x16, 32x32, 48x48, 64x64, 128x128, 256x256 PNG icons
- Installed to /usr/share/icons/

## Color Scheme

Primary Brand Color: #1E40AF (Blue)
Secondary Color: #DC2626 (Red - for security alerts)
Background: #F9FAFB (Light gray)
Text: #111827 (Dark gray)

## Notes

This is a placeholder branding directory. Actual production icons and logos
should be created by a professional designer and placed here before building
the final release.

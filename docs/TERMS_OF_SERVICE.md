**"Personal Data"** means any information relating to an identified or identifiable natural person.

## 3. DESCRIPTION OF SERVICES

### 3.1 Platform Overview

Blockd provides an interview integrity platform that enables Organizations to:

(a) Schedule and conduct remote video interviews;

(b) Monitor interview sessions for potential integrity violations;

(c) Analyze candidate responses for indicators of AI-generated or pre-prepared answers;

(d) Generate comprehensive security and analysis reports;

(e) Maintain audit trails for compliance and review purposes.

### 3.2 Blockd Browser

The Blockd Browser is a specialized application that includes:

(a) **Security Monitoring:** Detection of screen recording software, virtual machines, unauthorized processes, and other potential integrity threats;

(b) **Eye Tracking:** Continuous gaze analysis to detect reading patterns or off-screen focus;

(c) **System Telemetry:** Collection of system performance metrics and application activity;

(d) **Meeting Integration:** Detection and monitoring of video conferencing platforms (Google Meet, Zoom, Microsoft Teams);

(e) **Video Capture:** Recording capabilities for session documentation.

Our AI-powered analysis includes:

(a) Comparison of candidate responses against AI-generated baselines;

(b) Response timing and pattern analysis;

(c) Language pattern evaluation;

(d) Risk scoring and classification;

(e) Behavioral anomaly detection.

### 3.4 Service Availability

We strive to maintain 99.9% uptime for our Services but do not guarantee uninterrupted access. Scheduled maintenance will be communicated in advance when possible.

## 6. MONITORING AND SECURITY FEATURES

### 6.1 Comprehensive Monitoring Disclosure

**IMPORTANT: By using Blockd Services, particularly as an Interviewee, you acknowledge that the following monitoring occurs:**

### 6.2 Video and Audio Monitoring

During interview sessions, we capture:

- Continuous video recording via webcam (default 640x480 resolution at 30fps)
- Audio recording of all verbal communication
- Screen content if visible in the camera view
- Meeting platform interface and interactions

### 6.3 Eye and Gaze Tracking

Using computer vision technology, we monitor:

- Where you are looking on the screen (gaze position)
- When you look away from the screen (off-screen detection)
- Reading patterns that may indicate use of notes or other materials
- Attention and focus metrics
- Pupil measurements for engagement analysis
- Head position and movement

### 6.4 System-Level Monitoring

The Blockd Browser monitors your computer system for:

**Process Monitoring:**
- All running applications and processes
- Process creation and termination events
- Application signatures and paths
- Potentially suspicious or forbidden applications

**Security Detection:**
- Screen recording or screen capture software
- Virtual machine environments (VMware, VirtualBox, Hyper-V)
- Remote desktop software
- Browser automation tools
- Debugging or developer tools

**Activity Monitoring:**
- Window focus changes (switching between applications)
- Clipboard operations (copy/paste activity)
- Keyboard shortcuts (attempts to use blocked combinations)
- Connected displays and monitors
- Network connections and requests

### 6.5 Meeting Platform Detection

When you use video conferencing platforms, we detect:

- Which platform you are using (Google Meet, Zoom, Microsoft Teams)
- Meeting URLs and identifiers
- Meeting state (waiting room, in-call, etc.)
- Platform-specific interactions

### 6.6 Security Event Classification

Detected events are classified by severity:

| Severity | Description | Examples |
|----------|-------------|----------|
| **Critical** | Immediate integrity threat | VM detected, screen recording active |
| **High** | Significant concern | Suspicious process, unauthorized browser |
| **Medium** | Moderate concern | Multiple monitors, frequent window switches |
| **Low** | Minor observation | Occasional off-screen glance, clipboard use |

### 6.7 Limitations of Monitoring

Monitoring technology is not perfect. You acknowledge that:

(a) False positives may occur (legitimate activity flagged incorrectly);

(b) False negatives may occur (violations may go undetected);

(c) Environmental factors may affect accuracy;

(d) Monitoring results should be considered alongside other factors;

(e) Final hiring decisions remain with the Organization.
